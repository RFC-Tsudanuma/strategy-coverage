12def require_formation_position(s: StrategyState, formation_name: str) -> Position: 

13 """`get_my_position_in_formation` の結果を非 None として取り出す。 

14 

15 `get_my_position` が None を返すのは 

16 **`top_relative` フォーメーションの先頭ロボットの場合だけ**である 

17 (その場合は目標位置が定義できないため、呼び出し元が自機位置を基準に 

18 動くなどの対応を取ることになっている)。 

19 

20 したがってこの関数は `absolute` / `ball_relative` のフォーメーションに 

21 対してのみ使うこと。`top_relative` を渡す可能性がある場合は 

22 `formation.get_my_position_in_formation()` を直接呼んで None を処理すること。 

23 

24 契約が破れている場合は例外を投げる。従来はこの状況で 

25 `NoneType` の AttributeError になっていたので、失敗の仕方は変わらず、 

26 どのフォーメーションで破れたのかが分かるようになるだけである。 

27 """ 

28 # formation は utils.geometry を経由してこのモジュールを参照するため、 

29 # モジュールレベルで import すると循環参照になる。 

30 from formation import get_my_position_in_formation 

31 

32 position = get_my_position_in_formation(s, formation_name) 

33 if position is None: 

34 raise StrategyContractError( 

35 f"フォーメーション '{formation_name}' の目標位置が None です。" 

36 "top_relative フォーメーションの先頭ロボットでのみ起きるため、" 

37 "このフォーメーションでは起きない想定です"
